# Button

## Описание

Это задание предназначено для практики **проектирования компонентов дизайн-системы**
на примере компонента **Button**.

Фокус задания:
- перевод обычного CSS в **SASS (SCSS)**
- проектирование компонента
- понимание, как UI-компоненты масштабируются в дизайн-системе

---

## Цель

Научиться:
- использовать возможности SCSS (вложенность, миксины, переиспользование)
- проектировать гибкий и расширяемый Button
- работать с модификаторами и состояниями
- писать чистый и предсказуемый React-код

---

## Исходные условия

Вам выдан файл `style.css` с готовыми стилями кнопки, написанными на обычном CSS.

Ваша задача:

1. Переписать эти стили на **SCSS**
2. Реализовать React-компонент **Button**
3. Использовать SCSS как **CSS Modules**

---

## Структура проекта

```
Button/
├── Button.jsx
└── Button.module.scss
```

---

## Требования к стилям (SCSS)

Файл: `Button.module.scss`


Требования:
- использовать вложенность
- использовать переменные и миксины
- базовый класс `.button`
- отсутствие inline-стилей

Стили в документу прописаны на:
- варианты кнопки: `primary`, `secondary`, `outline`, `transparent`, `disabled`
- модификаторы: `circle`, `cta`
- состояние загрузки (`loading`)

---

## Требования к компоненту

Файл: `Button.jsx`

Компонент должен принимать следующие пропсы:
- `children`
- `className`
- `color`: `primary | secondary | outline | transparent | disabled`
- `circle` (boolean)
- `cta` (boolean)
- `loading` (boolean)
- все стандартные HTML-атрибуты кнопки (`onClick`, `type`, `disabled` и т.д.)

Компонент должен:
- корректно комбинировать классы, используем функцию getStyles
- поддерживать разные визуальные состояния
- отображать loader вместо контента при `loading=true`
- скрывать underline при `cta=true`
- быть расширяемым для будущих вариантов
- для отображения лоадера используйте компонент <Ellipsis /> от библиотеки иконок `lucide-react`;

---

## Ожидаемый результат

Компонент с API, эквивалентным следующему:

```jsx
<Button color="primary" loading>
    Отправить
</Button>
```
